# CA Kothari tools

Windows installers used with the CA Kothari workspace. They are downloaded from the workspace's Tools page by signed-in staff.

## Files

| File | Used for |
|---|---|
| Smart-Tally-Connector-v7.exe | Smart Tally Connector (Tally Connector and Smart Audit tools) |
| Smart-Tally-Import-Connector.exe | Smart Tally Import Connector (CC to Tally Mapper) |

The files are in the **Releases** section of this repository (tag `tools-1`).

## Notes

- Windows only. Tally Prime or Tally ERP 9 must be running on the same computer.
- Windows may show a "SmartScreen" notice for unsigned installers. Choose **More info**, then **Run anyway**, if the file came from the workspace Tools page.
- This repository holds installers only. It contains no client data.
